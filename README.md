# LOCALIB-MOBILE-APP



How to use:

1. Install Node.js on your computer
2. Install the Expo Go app on your mobile phone (Play Store / App Store)
3. Ensure your phone and computer are on the same Wi-Fi network
4. Clone the repository to your computer using VS Code
5. Open the repository in VS Code
6. Install dependencies by running: npm install
7. Start the development server by running: npx expo start
8. Scan the QR code in your terminal using Expo Go (Android) or the Camera app (iPhone) to view the app live on your phone
